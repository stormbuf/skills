## 四、不适合轻量 skill 的细节及处理

> 说明：没有正式规则被完全放弃；以下讨论的是「规则本身的细节不适合作 lightweight skill 的逐条内容」，已在 `ste-rules.md` 中降为原则级或仅英文场景。

| 对象 | 问题 | 处理 |
|---|---|---|
| Rule 1.5 的 22 类技术名词清单 | 类别多、示例词数百个；完整复制既超体量，也有版权与维护问题 | 只保留「技术名词须能归入官方类别、以项目术语表为准」；类别名做一句概述，不复制完整示例词表 |
| Rule 1.12 的 4 类技术动词清单 | 同上，且示例与具体行业强相关 | 只保留「技术动词须属于四类之一、优先用批准动词」的原则 |
| Rule 8.4–8.7 的英文计词细则 | 依赖英语「词」的计数口径，中文写作无法直接执行 | 仅英文场景保留；中文另定「汉字数」口径，不硬套 20/25 词 |
| Rule 8.3 括号 7 种用途 | 逐项保留价值低，中文括号用法与英文基本相同 | 压缩为一行概述，保留图号、缩写、补充说明等常用项 |
| GR-5 False friends | 主要针对拉丁语系母语者，中文母语者遇到的问题不同 | 原则级保留一句提醒，不作为中文写作硬要求 |
| GR-8 所有格 | 英文专属（`'s`），中文无对应形态 | 原则级保留；中文用「的」并避免「的」字堆叠 |

## 五、仅英文规则清单与中文处理

> 判定标准：规则依赖英语的冠词、时态、动词形态、-ing、连字符、词数等形态特征，中文无法逐条照搬。共 17 条正式规则整体标注「仅英文」；2.2 仅「连字符构词」部分属英文专属；GR-1、GR-2、GR-6、GR-8 与英文语法相关。

| 规则 | 英文依赖点 | 中文处理方式 |
|---|---|---|
| 1.4 | 动词/形容词的词形变化 | 中文无形态变化；固定动词词条即可 |
| 1.14 | 美式/英式拼写 | 中文不适用；英文术语保持原拼写 |
| 2.1 | 多词名词的英语词序 | 转为「长定语拆分」：修饰层级不超过 2–3 层 |
| 2.2 | 连字符构词 | 中文用简称，不用连字符模拟英文；连接号只表范围/组合 |
| 3.1 | 词典动词形式 | 中文无形态；统一动词词条 |
| 3.2 | 六种时态/形式 | 中文用「将/了/已」等时间标记，不用复合进行结构 |
| 3.3 | 过去分词作形容词 | 中文用「已……的」「……过的」 |
| 3.4 | 助动词＋过去分词 | 中文避免「被/由/所」复杂被动套叠，改主动句 |
| 3.5 | -ing 形式 | 中文避免「进行……」「……的」长定语，改短句 |
| 4.2 | 英语缩写（`don't` 等） | 中文无缩写；补全省略的主语和动词 |
| 4.5 | 冠词与指示形容词 | 中文用「一个/一种」「该/这个/上述」补偿；泛指不加限定 |
| 5.1 | 20 词上限 | 中文按「一句一动作、约 20–25 个汉字」 |
| 5.5 | 25 词上限（注释） | 中文按句意长度控制，不套英文词数 |
| 6.3 | 25 词上限 | 中文按约 25–35 个汉字控制 |
| 8.2 | 英语连字符规则 | 中文用连接号（如「北京—上海」）；复合词直接连写 |
| 8.4 | 冒号＝句号的计词规则 | 中文按「引导句简短、每项一句」执行 |
| 8.5 | 括号算一个词 | 中文按实际字数计 |
| 8.6 | 特定元素各算一个词 | 中文按「数字/单位/缩写/型号各算一个整体」执行 |
| 8.7 | 连字符词算一个词 | 中文按实际字数计 |
| 9.3 | 英语短语动词 | 中文避免「搞/弄/整」等口语动补式，用单一明确动词 |
| GR-1 | 连词 `that` | 中文用完整小句，无对应连词 |
| GR-2 | 介词 `with` | 中文注意「用/和/带有」歧义，工具与对象分开写 |
| GR-6 | 拉丁缩写 | 中文直接用「例如/即/等」 |
| GR-8 | 所有格 `'s` | 中文用「的」，避免「的」字堆叠 |

**补充说明**：
- 3.6（主动语态）不是纯英文规则：中文同样优先主动句，故按「完整纳入」处理；只有被动语态的形态判断（`be + 过去分词`）属英文。
- 8.1（禁分号）在中文中不是绝对禁令，但「长句拆短」的原则通用，故按「完整纳入」处理并注明中文可更宽。
